# Examples

- `cube.stl` — a 1 mm unit cube (binary STL, 12 triangles, watertight). Used by the "mesh2cad batch (example session)" run configuration and by a test.
- `session.jsonl` — a batch of commands for `mesh2cad batch`. Paths are relative to this folder.
- `test-meshes/` — synthetic meshes made with Blender for trying the mesh, repair, hole, shell, selection and alignment commands, each with a batch session. See its README.
