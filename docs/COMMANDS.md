# Commands

Generated by `scripts/gen_commands.py` from the registry; do not edit by hand.
Every command works the same from the desktop app (Tools menu), `mesh2cad run`/`batch`,
JSON-RPC (`mesh2cad-rpc` or the app's local socket) and MCP (`mesh2cad-mcp`, where dots
become underscores: `mesh.repair` is the tool `mesh_repair`).

Lengths are millimetres; objects are referred to by id (see `doc.list`).

Long commands (`quad.remesh`, `surface.build`, `deviation.compute`, `mesh.simplify`,
`mesh.remesh`, `primitive.trim`) say which stage they are at while they run: as
`rpc.progress` notifications over JSON-RPC, as `notifications/progress` over MCP when the
tool call carries `_meta.progressToken`, and in the desktop app's status bar.

## fillet

### `fillet.fit`

Round edges of a solid with the constant-radius fillet a scan shows (ADR-033): the edge nearest each of edge_points (between two planes, cylinders, cones or spheres, as primitive.trim, primitive.box and solid.boolean make them) gets a rolling-ball fillet whose radius brings the solid closest to the selected band of the mesh, found by rounding at trial radii (about 25 tries). radius_mm rounds at that radius instead, for example a nominal value. Adds a solid object; the solid is unchanged. Fails, adding nothing, when the band's P95 distance to the rounded solid is above max_residual_mm or Open CASCADE cannot round the edges (a radius too large for the faces either side). *(changes the document)*

| Parameter | Type | Required | Notes |
| --- | --- | --- | --- |
| `edge_points` | array | yes | A point near each edge to round, such as a click on it. |
| `max_residual_mm` | number |  | Largest P95 distance from the band to the rounded solid. Default `0.1`. |
| `name` | string |  |  |
| `radius_mm` | number |  | Round at this radius instead of fitting one. |
| `selection_id` | selection id | yes | The fillet's band on the mesh. |
| `solid_id` | solid id | yes | The solid with the sharp edges. |

### `mesh.segment`

Split a mesh into spheres, cylinders and planes (CGAL region growing, in that order, each region refit by least squares) and the organic rest. Each region becomes a selection; the result lists each region's kind, area, fit and primitive. A region is kept only when its area reaches min_area_mm2 and its RMS distance to the primitive is within max_distance_mm. Run it on an even mesh at working density (mesh.remesh): the normals of a raw scan's small triangles are too noisy for the angle limit. The mesh is unchanged; it must be manifold (mesh.repair). *(changes the document)*

| Parameter | Type | Required | Notes |
| --- | --- | --- | --- |
| `id` | mesh id | yes |  |
| `kinds` | array |  | The primitives to look for. Default `["plane", "cylinder"]`. |
| `max_angle_deg` | number |  | Largest angle between a face normal and the primitive's normal there. Default `10`. |
| `max_distance_mm` | number |  | Largest distance from a face to its region's primitive. Default `0.1`. |
| `min_area_mm2` | number |  | Smaller regions are left organic; 0 = 1% of the mesh's area. Default `0`. |

## primitive

### `primitive.align`

Make planes, cylinders and cones exactly parallel, perpendicular or at a set angle to a reference, then refit everything but the direction to the regions they were fitted to. The reference is the mean of reference_ids, a world axis, or a world plane; with none, the mean of the primitives' own directions (parallel only). Angles have their CAD meaning: a plane is measured by its normal and a cylinder or cone by its axis, so a cylinder perpendicular to a plane has its axis along the normal. Replaces the primitives in place as one step. Fails, changing nothing, for a sphere, a turn whose way is undefined, a region that is gone, or a new P95 above max_residual_mm. The result gives each primitive's turn in degrees and its P95 before and after. *(changes the document)*

| Parameter | Type | Required | Notes |
| --- | --- | --- | --- |
| `angle_deg` | number |  | The angle, for relation angle. |
| `axis` | `x` \| `y` \| `z` |  | A world axis as the reference, a line. |
| `ids` | array | yes | The primitives to align. |
| `max_residual_mm` | number |  | Largest P95 distance allowed after aligning. |
| `plane` | `xy` \| `yz` \| `zx` |  | A world plane as the reference. |
| `reference_ids` | array |  | Primitives whose mean direction is the reference: all planes, or all cylinders and cones. |
| `relation` | `parallel` \| `perpendicular` \| `angle` |  | Default `"parallel"`. |

### `primitive.box`

Make an exact box solid: fitted to the faces of a selection (six planes, opposite ones parallel and neighbouring ones perpendicular, nearest to the selected vertices, from the faces' normals and then Gauss-Newton steps), or from a size, centre and axes. Given with a selection, size_mm, center and axes replace the fitted ones, for example to snap the sizes to nominal values. Sides the selection does not reach stay at its extent. Adds a solid object, which solid.boolean can fuse or cut and solid.export can write; fails, adding nothing, when the fit's P95 distance is above max_residual_mm. *(changes the document)*

| Parameter | Type | Required | Notes |
| --- | --- | --- | --- |
| `axes` | array |  | Three perpendicular, right-handed directions (scaled to unit length); default the world axes, or the fitted ones. |
| `center` | array |  | The box's centre; default the origin, or the fitted one. |
| `max_residual_mm` | number |  | Largest P95 distance from the selected vertices to the fitted box. Default `0.1`. |
| `name` | string |  |  |
| `selection_id` | selection id |  | Faces to fit the box to; required unless size_mm is given. |
| `size_mm` | array |  | Edge lengths along the three axes. |

### `primitive.fit`

Fit an exact, unbounded plane, cylinder, sphere or cone to the faces of a selection by least squares, starting from CGAL's estimate, and add it as a primitive. With kind "auto" it takes the simplest kind that fits about as well as any. Fails, adding nothing, when 95% of the region's vertices are not within max_residual_mm of the surface. The result gives the primitive, its RMS, largest and P95 distance, and the region's bounding box. *(changes the document)*

| Parameter | Type | Required | Notes |
| --- | --- | --- | --- |
| `kind` | `auto` \| `plane` \| `cylinder` \| `sphere` \| `cone` |  | Default `"auto"`. |
| `max_residual_mm` | number |  | Largest P95 distance from the region's vertices to the surface. Default `0.1`. |
| `selection_id` | selection id | yes |  |

### `primitive.solid`

Make a fitted cylinder or sphere (primitive.fit) a solid of its exact surface, to fuse to or cut from another solid with solid.boolean, such as a true-cylinder hole through an organic body. A sphere is whole; a cylinder runs along its axis, centred on the fitted region, length_mm long (0 = as long as the region). radius_mm replaces the fitted radius, for example to drill a fuzzy scanned hole clean. Adds a solid object; fails for a plane or cone. *(changes the document)*

| Parameter | Type | Required | Notes |
| --- | --- | --- | --- |
| `id` | primitive id | yes | The cylinder or sphere primitive. |
| `length_mm` | number |  | A cylinder's length; 0 = the length of the region it was fitted to. Default `0`. |
| `name` | string |  |  |
| `radius_mm` | number |  | The solid's radius; 0 = the fitted radius. Default `0`. |

### `primitive.trim`

Make a solid with sharp edges from fitted primitives (primitive.fit): each is bounded by the mesh's box, grown by a tenth of its diagonal, and all are split against each other (Open CASCADE General Fuse). A split face is kept when min_coverage of its area lies within max_distance_mm of the mesh; the kept faces are sewn into a solid and faces of one primitive merged. The faces are the primitives' exact planes, cylinders, spheres and cones. Adds a solid object; fails, adding nothing, naming where the faces leave the solid open (a primitive there is missing or does not fit), or unless the result is one valid closed solid of positive volume. *(changes the document)*

| Parameter | Type | Required | Notes |
| --- | --- | --- | --- |
| `max_distance_mm` | number |  | A point of a split face lies on the mesh when it is this close. Default `0.5`. |
| `mesh_id` | mesh id | yes | The mesh they were fitted to. |
| `min_coverage` | number |  | Share of a split face's area that must lie on the mesh for it to be kept. Default `0.9`. |
| `name` | string |  |  |
| `primitive_ids` | array | yes | The primitives to trim. |

## quad

### `quad.remesh`

Make a quad control cage from a closed mesh with Instant Meshes, then close it: faces on non-manifold edges are dropped, open loops filled and faces pointed outward. Loose parts (such as the head of a thin post whose stem the remesher missed) are joined to the main part with a tube of quads, or left out and counted when they cannot be. Guides, polylines drawn on the mesh, lay out the patches by hand: cage edges run along them. With keep_outline, an open mesh (a scanned sheet such as a lid) gives an open cage: its longest boundary loop stays open, cage edges follow it, and the faces point the way the mesh does. Adds a quad_layout object; the mesh is unchanged. *(changes the document)*

| Parameter | Type | Required | Notes |
| --- | --- | --- | --- |
| `crease_angle_deg` | number |  | Align the quads to edges sharper than this; 0 = treat the surface as smooth. Default `0`. |
| `guides` | array |  | Polylines on the mesh, in mm, that cage edges should follow (manual patch layout); each needs two or more points within a cage edge length of the surface. Default `[]`. |
| `id` | mesh id | yes |  |
| `join_parts` | boolean |  | Join loose closed parts to the main one instead of leaving them out. Default `true`. |
| `keep_outline` | boolean |  | Leave the longest boundary loop open, for a sheet that surface.build thickens. Default `false`. |
| `name` | string |  |  |
| `smooth_iterations` | integer |  | Rounds of smoothing that pull the cage vertices back onto the mesh. Default `2`. |
| `target_faces` | integer |  | Approximate number of quads in the cage. Default `2000`. |

## sketch

### `sketch.section`

Cut a mesh with a plane and add a sketch of the cut: each closed piece becomes a loop of lines, arcs and splines within max_error_mm of the section points (a full circle when it is one). The plane is an origin plane (xy, yz or zx), a fitted plane primitive, or a point and a normal, moved offset_mm along its normal. Pieces that run into a hole or border are left out and counted. Fails, adding nothing, if no piece closes. Sketches are fitted, not constrained. *(changes the document)*

| Parameter | Type | Required | Notes |
| --- | --- | --- | --- |
| `id` | mesh id | yes | The mesh to cut. |

## surface

### `surface.build`

Build a closed B-rep solid from a quad layout: fit the cage so its Catmull-Clark limit surface follows the mesh, convert the limit surface to B-spline faces (exact where the cage is regular, close-fitting caps at irregular vertices) and sew them. A fit that folds the surface (faces meeting at more than 10 degrees) is made again with twice the smoothing, up to four fits in all. Rectangles of cage quads, bounded by lines traced from the irregular vertices, are merged into one face each. With refine_to_mm, a fit farther from the mesh than that (95th percentile) has its cage subdivided once and is fitted again, up to max_refinements times. An open cage (from quad.remesh keep_outline) needs thickness_mm: its fitted sheet becomes a wall that thick, behind the faces' side, with a sharp-edged rim. Each flat area (a selection of the mesh and a plane fitted to it with primitive.fit) holds the cage vertices over it on the plane while fitting, so the surface there is that plane, without the scan's noise and bumps, and blends into the rest at the area's edge. Adds a solid object; the quad layout and mesh are unchanged. Fails, adding nothing, unless the result is one valid closed solid of positive volume whose faces, after the last fit, meet at no more than 90 degrees. *(changes the document)*

| Parameter | Type | Required | Notes |
| --- | --- | --- | --- |
| `fit` | boolean |  | Fit the cage to the mesh first. Default `true`. |
| `flat` | array |  | Areas held flat while fitting, each {selection_id, plane_id}: faces of the mesh and a plane primitive fitted to them (primitive.fit). Cage vertices whose closest mesh face is selected stay on the plane. Needs fit. Default `[]`. |
| `id` | quad_layout id | yes | The quad layout. |
| `isolation_level` | integer |  | Refinement around irregular vertices: higher gives smaller caps and more faces' pieces. Default `2`. |
| `iterations` | integer |  | Rounds of fitting. Default `3`. |
| `max_refinements` | integer |  | Most subdivisions refine_to_mm may make. Default `2`. |
| `max_sample_distance_mm` | number |  | Mesh points farther than this from the surface are left out of the fit (parts the cage does not cover); 0 = the mean cage edge length. Default `0`. |
| `max_samples` | integer |  | Mesh vertices used for fitting (evenly thinned beyond this). Default `60000`. |
| `merge` | boolean |  | Merge rectangles of cage quads into one face each (fewer faces, same surface). Default `true`. |
| `mesh_id` | mesh id |  | The mesh to fit to; required unless fit is false. |
| `name` | string |  |  |
| `refine_to_mm` | number |  | While the fit's 95th-percentile distance to the mesh is above this, subdivide the fitted cage once (four times the quads, same layout) and fit again; 0 = off. Default `0`. |
| `smoothing` | number |  | How strongly the cage keeps its own shape while fitting. Default `0.05`. |
| `thickness_mm` | number |  | For an open cage: thicken the fitted sheet by this much, against its faces' direction; required for an open cage and only for one. Default `0`. |

## view

### `view.render`

Draw the visible objects as the app's viewport shows them, so an agent can see the document: meshes grey (red where a back face shows, deviation colours when a deviation of the mesh is visible), solids blue, primitives green, quad layout edges orange and sketches cyan over everything. selection_id marks a selection's faces orange, selection_ids marks each listed selection in its own colour (the app's, listed in color_legend), and highlight_id draws one object yellow. The view is orthographic and framed on what is drawn, or on focus_id with 20% padding; view quad is a 2 x 2 sheet of front, right, top and iso, labelled, all at one scale (framing sphere). With path the PNG is written there; without it nothing is written and the result carries the PNG as image.data_base64. Needs no GPU or display. Over MCP the picture is also returned as an image. *(writes a file)*

| Parameter | Type | Required | Notes |
| --- | --- | --- | --- |
| `axes` | boolean |  | Draw an X (red), Y (green), Z (blue) triad in the bottom-left corner. Default `false`. |
| `direction` | array |  | From the part towards the camera, instead of a standard view. |
| `focus_id` | object id |  | Frame this object's bounds with 20% padding, still drawing everything visible. |
| `framing` | `box` \| `sphere` |  | box fits the view tightly; sphere frames the bounding sphere, the same scale and centre from every direction (as each quad panel does). Default `"box"`. |
