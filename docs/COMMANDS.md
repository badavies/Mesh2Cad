# Commands

Generated by `scripts/gen_commands.py` from the registry; do not edit by hand.
Every command works the same from the desktop app (Tools menu), `mesh2cad run`/`batch`,
JSON-RPC (`mesh2cad-rpc` or the app's local socket) and MCP (`mesh2cad-mcp`, where dots
become underscores: `mesh.repair` is the tool `mesh_repair`).

Lengths are millimetres; objects are referred to by id (see `doc.list`).

## align

### `align.datum`

3-2-1 datum alignment: the primary selection's plane becomes Z = 0, the secondary's Y = 0 and the tertiary's X = 0. The part ends up on the positive side of each plane. *(changes the document)*

| Parameter | Type | Required | Notes |
| --- | --- | --- | --- |
| `flip_primary` | boolean |  | Put the part below Z = 0 instead. Default `false`. |
| `id` | integer | yes |  |
| `primary` | integer | yes | Selection id of the primary datum face. |
| `secondary` | integer |  | Selection id of the secondary datum face. |
| `tertiary` | integer |  | Selection id of the tertiary datum face. |

### `align.principal`

Automatic alignment: move the mesh so its principal axes lie along X (longest), Y and Z (shortest), with the origin at the centroid or the bounding box. *(changes the document)*

| Parameter | Type | Required | Notes |
| --- | --- | --- | --- |
| `id` | integer | yes |  |
| `origin` | `centroid` \| `bounds_center` \| `bounds_bottom_center` |  | Default `"centroid"`. |

### `align.reset`

## holes

### `holes.fill`

Fill open boundaries with patches that blend into the surrounding surface. Holes larger than the limits are left open so real openings survive. *(changes the document)*

| Parameter | Type | Required | Notes |
| --- | --- | --- | --- |
| `fair` | boolean |  | Refine and fair the patch to match the surrounding curvature. Default `true`. |
| `id` | integer | yes |  |
| `max_edges` | integer |  | Leave holes with more boundary edges open; 0 = no limit. Default `0`. |
| `max_perimeter_mm` | number |  | Leave holes with a longer boundary open; 0 = no limit. Default `0`. |
