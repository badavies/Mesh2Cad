# Commands

Generated by `scripts/gen_commands.py` from the registry; do not edit by hand.
Every command works the same from the desktop app (Tools menu), `mesh2cad run`/`batch`,
JSON-RPC (`mesh2cad-rpc` or the app's local socket) and MCP (`mesh2cad-mcp`, where dots
become underscores: `mesh.repair` is the tool `mesh_repair`).

Lengths are millimetres; objects are referred to by id (see `doc.list`).

## align

### `align.datum`

3-2-1 datum alignment: the primary selection's plane becomes Z = 0, the secondary's Y = 0 and the tertiary's X = 0. The part ends up on the positive side of each plane. *(changes the document)*

| Parameter | Type | Required | Notes |
| --- | --- | --- | --- |
| `flip_primary` | boolean |  | Put the part below Z = 0 instead. Default `false`. |
| `id` | integer | yes |  |
| `primary` | integer | yes | Selection id of the primary datum face. |
| `secondary` | integer |  | Selection id of the secondary datum face. |
| `tertiary` | integer |  | Selection id of the tertiary datum face. |

### `align.principal`

Automatic alignment: move the mesh so its principal axes lie along X (longest), Y and Z (shortest), with the origin at the centroid or the bounding box. *(changes the document)*

| Parameter | Type | Required | Notes |
| --- | --- | --- | --- |
| `id` | integer | yes |  |
| `origin` | `centroid` \| `bounds_center` \| `bounds_bottom_center` |  | Default `"centroid"`. |

### `align.reset`

Undo every alignment applied to a mesh, returning it to its scanned pose. *(changes the document)*

| Parameter | Type | Required | Notes |
| --- | --- | --- | --- |
| `id` | integer | yes |  |

### `align.symmetry`

Automatic alignment by the best mirror-symmetry plane: that plane becomes X = 0, Y and Z follow the principal axes within it. Reports how far mirrored points land from the surface, so a poor fit shows. *(changes the document)*

| Parameter | Type | Required | Notes |
| --- | --- | --- | --- |
| `id` | integer | yes |  |
| `origin` | `centroid` \| `bounds_center` \| `bounds_bottom_center` |  | Positions the part in Y and Z; X = 0 stays on the plane. Default `"centroid"`. |

## surface

### `surface.build`

Build a closed B-rep solid from a quad layout: fit the cage so its Catmull-Clark limit surface follows the mesh, convert the limit surface to B-spline faces (exact where the cage is regular, close-fitting caps at irregular vertices) and sew them. Adds a solid object; the quad layout and mesh are unchanged. Fails, adding nothing, unless the result is one valid closed solid. *(changes the document)*

| Parameter | Type | Required | Notes |
| --- | --- | --- | --- |
| `fit` | boolean |  | Fit the cage to the mesh first. Default `true`. |
| `id` | integer | yes | The quad layout. |
| `isolation_level` | integer |  | Refinement around irregular vertices: higher gives smaller caps and more faces' pieces. Default `2`. |
| `iterations` | integer |  | Rounds of fitting. Default `3`. |
| `max_sample_distance_mm` | number |  | Mesh points farther than this from the surface are left out of the fit (parts the cage does not cover); 0 = the mean cage edge length. Default `0`. |
| `max_samples` | integer |  | Mesh vertices used for fitting (evenly thinned beyond this). Default `60000`. |
| `mesh_id` | integer |  | The mesh to fit to; required unless fit is false. |
| `name` | string |  |  |
| `smoothing` | number |  | How strongly the cage keeps its own shape while fitting. Default `0.05`. |
